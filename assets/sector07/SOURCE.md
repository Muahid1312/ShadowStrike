# Sector 07 asset sources

Original compound/buildings, observation tower/stairs, barriers, barrels, sandbags, target art, escarpments, PBR tiles and ground wear mask are generated by `tools/build_sector07_assets.py` and `tools/build_sector07_textures.py` using Blender4.3.2 and development-only NumPy/Pillow. Runtime uses committed local GLB/texture assets; there is no asset-generation or internet dependency during play.

The cargo mesh/materials are adapted from the official Godot TPS Demo under **CC-BY3.0**. See [ATTRIBUTION.txt](ATTRIBUTION.txt), [original upstream licence](TPS_LICENSE.txt) and [provenance.json](provenance.json) for exact paths, authors, modifications and source digest. Those assets were actually retrieved; complete selected files were extracted with ZIP CRC checks from the bounded source download. No other source-demo geometry or gameplay code is included.

To rebuild, obtain the upstream demo with `level/geometry/models/props.glb` and its `level/textures/props/mid_cargo_box_{albedo,normal,orm}.png` files, then from this repository:

```bash
python3 tools/build_sector07_textures.py
blender -b --factory-startup --python tools/build_sector07_assets.py -- --tps-source /path/to/tps-demo-master
./tools/godot.sh --headless --editor --import --quit
```

The original-texture generator preserves cargo textures. The Blender pipeline normalizes the licensed cargo mesh, batches original art by spatial chunk/material, preserves authored PBR tint factors and shares identical embedded images. No Draco decoder is required. `collision_layout.json` is the same deterministic static collision input on host and clients. Hit logic/spawn coordinates remain in their original scripts.
